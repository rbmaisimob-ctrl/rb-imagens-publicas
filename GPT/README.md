# Pasta GPT — RB+ Negócios Imobiliários

Esta pasta é a área de entrada dos materiais criados e preparados pelo ChatGPT para o fluxo editorial da RB+.

## Fluxo de trabalho
1. GPT: cria textos e peças para Site/Tecimob, Instagram e Perfil da Empresa no Google.
2. Agente A: confere dados, textos, imagens e formatos; organiza os materiais validados na pasta de publicação já utilizada.
3. Agente B: publica somente os materiais conferidos e aprovados pelo Agente A.

## Organização dos materiais
Criar uma subpasta por conteúdo, com data e assunto no nome (ex.: `AAAA-MM-DD-assunto`). Incluir textos finais, imagens correspondentes e instruções necessárias para cada canal.

## Regras
- Não declarar que um arquivo foi enviado sem confirmar que ele está no repositório.
- Não alterar materiais já aprovados sem autorização.
- Não inventar nem modificar dados factuais sem fonte.
- O repositório é público: não incluir senhas, credenciais, dados pessoais de clientes ou informações confidenciais.
- O Agente B deve usar apenas materiais conferidos e aprovados pelo Agente A.

Esta pasta é a área de entrada do GPT; a pasta de publicação existente continua sendo a área de saída validada.
